## 成绩与比较

历史PDF复核将数值记录从43条补至156条、315项指标；加入Kimi后为189条数值记录、357项指标。22条仅图示、18条仅定性、53条不适用分别标注。原始成绩与配置仍可查询，不用“未填成绩”把不同情况混在一起。

能力类、已确认的精确百分数或计数指标可以绘成散点，指标与配置可以切换。范围、倍率、多个指标、带“至少一次”等限定的成绩不转换为统一分数。防护／行为指标在其对应评测下单独展示，不混作能力指标；违规率、攻击成功率和风险提示放行率按越低越好解释；上下界和区间不作为精确点。曲线没有数值标注时不估读。

直接比较应逐项核对：题集和版本、子集、原始指标、pass@k、采样和时间预算、工具 / harness、judge、源码访问权限、防护开关、生产 / 研究配置及模型快照。目前所有 `comparisonGroup` 都为 `null`，不绘制趋势连线。

## 日期与后续补测

模型日期来自现有整理数据，原始日期证据与口径在模型总表中保留。原快照4个、新增GLM系列3个模型只有月精度，共7个，导入时移除旧数据里作为占位的日，避免伪精确。

图表横轴为模型日期，不是报告发布日期。后续补测使用原记录的配置、备注与显式laterDisclosure标识；仅在备注里提及“未采用后续结果”不会打后测标签。当前尚无完整、独立核验的成绩披露日期字段，补齐该字段是后续工作。

## 来源定位

每条记录保留官方 URL、重定向文档 URL、章节 / 表图、PDF 文件页码及归档路径。文件页码从第一页计数，与印刷页脚可能不同。网页转制 PDF 与厂商原始 PDF 分别标识。

历史PDF归档包含69个文件、4774页；新增厂商46份资料包含PDF、HTML、MHTML和图片，独立保存在`sources/vendors/`，由`data/documents.json`索引。网页和图片用章节／表格定位，不生成虚构页码。多个模型可共用同一原文。PDF 数量不表示独立研究数量。104 条访问日志保留失败尝试，403 错误页不视为报告正文。
