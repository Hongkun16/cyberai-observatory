## 成绩与比较

数值记录从43条补至156条，保留317项分配置指标；22条仅图示、18条仅定性、37条证据未确认分别标注。原始成绩与配置仍可查询，不用“未填成绩”把不同情况混在一起。

能力类、已确认的精确百分数或计数指标可以绘成散点，指标与配置可以切换。范围、倍率、多个指标、带“至少一次”等限定的成绩不转换为统一分数。拒答率即使是百分数，也不计入能力图；上下界和区间不作为精确点。曲线没有数值标注时不估读。

直接比较应逐项核对：题集和版本、子集、原始指标、pass@k、采样和时间预算、工具 / harness、judge、源码访问权限、防护开关、生产 / 研究配置及模型快照。目前所有 `comparisonGroup` 都为 `null`，不绘制趋势连线。

## 日期与后续补测

模型日期来自现有整理数据，原始日期证据与口径在模型总表中保留。4 个记录只有月精度，导入时移除旧数据里作为占位的日，避免伪精确。

图表横轴为模型日期，不是报告发布日期。后续补测使用原记录的配置、备注与显式laterDisclosure标识；仅在备注里提及“未采用后续结果”不会打后测标签。当前尚无完整、独立核验的成绩披露日期字段，补齐该字段是后续工作。

## 来源定位

每条记录保留官方 URL、重定向文档 URL、章节 / 表图、PDF 文件页码及归档路径。文件页码从第一页计数，与印刷页脚可能不同。网页转制 PDF 与厂商原始 PDF 分别标识。

归档包含 69 个文件、4774 页；多个模型可共用同一原文。PDF 数量不表示独立研究数量。104 条访问日志保留失败尝试，403 错误页不视为报告正文。

## 下一轮工作

优先提取同一报告、同一设置下的历史模型重跑成绩，记录独立的指标定义、模型快照日期、报告日期、图表定位和比较组。只有核定后的比较组才允许绘制连接曲线。任何外推或分析结论都应与原文成绩分开保存。
